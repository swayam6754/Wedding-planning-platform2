# Wedding Planning Platform 💍

A simple Flask-based web application designed to assist users in wedding planning.

## Features
- Home page with introduction
- Vendor management page
- Wedding checklist
- Clean UI using reusable templates

## Technologies Used
- Python (Flask)
- HTML
- CSS

## How to Run This Project
1. Install Flask using `pip install flask`
2. Run the app using `python app.py`
3. Open browser and visit `http://127.0.0.1:5000/`

## Project Purpose
This project was created to understand Flask routing, templates, and basic frontend design.
